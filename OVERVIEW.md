# KDE "FATTO" desktop widget
## Objective
A desktop widget that will simplify user daily work giving easy acces to a tool to measure time spent on a task

## Context 
A KDE desktop widget that will connect to "FATTO" web application and polling data every certain time from it.
The widget will show all the card scheduled for the current day. 
The user will be able to review them, but the main functionality will be the timer. In fact, the user will pick from those cards the one he is going to work on and a clearly visibile button will let him to start or pause the timer.

## Constraints
* use "fatto-kanban" mcp tools when needed
* access /data2/liwe/cf-liwe3/fatto/app/specs/kanban-specs.md for module documentation
* when switching cards timer must show the time spent in the current date and the whole time spent on that card.
